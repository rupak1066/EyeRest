# Eye_Rest_Reminder

An **MFC C++ application** designed to help reduce eye strain by reminding you to take regular breaks while working on your computer. 

## Key Features

* **Customizable Timers**: Users can easily set their preferred Work Time and Rest Time directly when the reminder window pops up.
* **Force Work Mode**: If you are in the middle of something urgent, you can force the app to stay in Work Mode and send it to the background so your screen remains uninterrupted.
* **Windows Startup Integration**: The application can be configured to launch automatically at Windows Startup, running quietly as a background process as soon as you log in.
